# ALMA-Hardware-Firmware
ALMA is a Smart Medical Dispenser developed to schedule and dispense specific doses of 2 types of medicines and as well as alert the user or caregiver when it is ready to be taken. 

Software: Arduino IDE
Hardware: ESP32-38 pin with Shield, DHT11, PWM Servo Driver, LCD Screen, Max30102, SG90 Server Motor, Laser Module, PhotoResistor, UltraSonic Sensor

This repository only contains code for the device firmware before app integration. Some minor changes will vary upon reception of client and app integration.
